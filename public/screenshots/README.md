# PWA Screenshots

This directory should contain screenshots of your application for the PWA manifest.

## Required Screenshots:

1. **screenshot-wide.png** (1280x720 or larger)
   - Wide format screenshot for desktop displays
   - Shows the application dashboard or main interface

2. **screenshot-narrow.png** (750x1334 or similar mobile dimensions)
   - Narrow format screenshot for mobile displays
   - Shows the mobile view of the application

## How to Create Screenshots:

1. Open your application in a browser
2. Use browser DevTools to set appropriate viewport size
3. Take a screenshot using browser tools or screenshot utilities
4. Save the screenshots in this directory with the names specified above

Note: These screenshots are optional but enhance the PWA installation experience on supported platforms.
